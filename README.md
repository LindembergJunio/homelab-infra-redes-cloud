# Homelab — Infraestrutura, Redes e Cloud

Laboratório prático de estudos e experimentação em infraestrutura de TI, redes e cloud, desenvolvido de forma incremental. O objetivo é construir ambientes, implementar serviços, testar configurações e documentar problemas e soluções.

O laboratório utiliza ferramentas como VirtualBox, Packet Tracer, Linux, Windows Server, PostgreSQL e tecnologias de virtualização, redes e cloud.

**Status atual:** Fase 02 — Switching e VLANs (em andamento).
